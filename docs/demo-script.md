# 时块 BlockFlow · 90 秒演示脚本（Demo Script）

> **总时长：90 秒。** 目标：在 90 秒内展示「批量输入 → 固定+补排 → 冲突提示 → 规则管理 → 计时与离开确认 → 复盘历史 → 移动/深色/PWA」全部亮点。
> **前提**：双击 `index.html` 打开（`file://` 即可）；PWA 段可选，用 `http://localhost:8080` 演示更佳。
> **建议**：提前把示例数据准备为「英语 15:00–17:00 固定」已存在，冲突步骤才可稳定复现。

## 演示前 10 秒准备

- 打开首页「今日」，窗口置于响应式模式，预置 375px 宽度。
- 确认设置页「离开提醒阈值」为默认 5 分钟。

## 时间轴

| 时间 | 步骤 | 操作 | 讲解词（要点） |
| --- | --- | --- | --- |
| 0–12s | 1. 批量输入 | 新建页输入「英语 / Python / AI 开发 / 运动」，批量时长 `30, 60, 90`（运动留空→自动估时），点「添加到当天」 | 「一次输入多个任务，留空时长会按名称自动估算。」 |
| 12–24s | 2. 固定时间 | 新建「英语」，安排方式「固定时间」，目标 `180` 分钟，`15:00–17:00`，今天，添加 | 「固定时间就是硬约束，几点到几点做什么。」 |
| 24–38s | 3. 固定+补排 | 回到「今日」，指出时间线：`英语 · 固定 15:00–17:00`，以及自动补排的「剩余安排」段 | 「固定 2 小时，剩余 1 小时被自动排到其他空档。」 |
| 38–48s | 4. 冲突提示 | 再添加一个同 `15:00–17:00` 的固定任务 | 「固定时段已被占用——红色提示 + 滚动可见，不覆盖、不静默失败。」 |
| 48–58s | 5. 规则管理 | 打开设置页「时间规则表」，暂停或修改一条规则 | 「所有固定/偏好任务在这里统一编辑、暂停、恢复、替换、删除，保存即重排。」 |
| 58–72s | 6. 计时+离开 | 执行页选「英语」开始；切走/锁屏模拟离开超过阈值，返回时弹窗选「全部不计入」 | 「离开确认四个选项，这里选不计入——已用时间不变。」 |
| 72–80s | 7. 重排 | 指出剩余时间更新，后续任务被重新排列 | 「选择后剩余部分自动重排，进度不会被推翻。」 |
| 80–86s | 8. 复盘历史 | 切到「复盘」看计划/实际/中断/偏差，再切「历史」查看某天 | 「每一步都留下可回溯的记录。」 |
| 86–90s | 9. 移动/深色/PWA | 切到 375px 手机布局；打开深色模式；进设置页展示「安装到桌面」入口 | 「移动端优先、深色可用、可安装到桌面离线打开。」 |

## 备用精简版（若时间被压缩到 60 秒）

**输入 → 固定+补排 → 冲突 → 开始计时 → 离开不计入 → 复盘。** 每步一句话，跳过规则管理与响应式展示。

## 演示异常兜底

- 任何失败（输入空、时长非法、固定冲突、存储不可用、导入格式错误）都会出现**红色提示并滚动到可见区域**，不会无响应。
- 若提示不在视口，演示前先滚动到提示位置；Toast 与内联提示会同时出现。

## 演示红线

- 演示文案只涉及任务与时间，**不包含任何学习、健身、饮食或健康建议**。
- 全程不联网、不登录、不上传数据。
