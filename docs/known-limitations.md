# 时块 BlockFlow · 已知限制（Known Limitations）

> 封版说明：以下为当前版本**已知且接受**的限制，均为有意取舍，不影响核心「输入 → 排程 → 执行 → 复盘」闭环。

## 运行形态

- **Service Worker / 安装到桌面仅在 http(s) 下可用**，`file://` 下自动跳过（不影响正常使用）。离线与安装能力需通过 `http://localhost` 或 https 访问。
- 离线能力已在 `http://localhost:8080` 实测通过；`file://` 直开能力以协议判断 + try/catch 保证，未在本机内置浏览器实测。

## 数据与存储

- 数据仅存于本机浏览器 localStorage（键 `blockflow.v1`）；**清除浏览器数据会导致数据丢失**，请使用设置页「导出数据」自行备份。
- 导入为覆盖式：导入成功会替换当前全部数据（导入前有二次确认，覆盖前写入 `blockflow.v1.bak` 备份键作为回滚点）。
- 不支持多设备自动同步（无账号、无云同步，符合产品定位）。

## 排期与计时

- 排期不把任务安排到早于当前时刻的时间；当日容量不足时以「缩短 / 顺延 / 调整」方案呈现，需用户选择，不自动丢弃任务。
- 计时基于时间戳恢复，但应用需处于前台或后台未被浏览器完全冻结；完全关闭标签页期间的离开区间以重新打开时的时间戳计算。
- 离开确认只作用于当前正在执行的任务。

## 界面与交互

- 不支持任务拖拽排序，任务按计划开始时间排序。
- 移动端优先设计；桌面为大屏布局，未针对超宽屏做专门优化。

## PWA 元数据

- 因未提供**真实应用截图**，Manifest 暂不包含 `screenshots`（不伪造尺寸，保持基本 Manifest 可用）。

## 明确不做（产品边界）

- 不添加英语学习方法、健身动作 / 运动处方、饮食 / 医疗 / 健康类建议。
- 不做账号系统、支付、云同步、多人协作。
- 不做小程序、原生 App、后端服务；不写 API Key；不将用户数据发送到任何外部服务。
